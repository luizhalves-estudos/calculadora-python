# Calculadora em Python

## 📌 Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de praticar os conceitos básicos de programação em Python.

A aplicação permite que o usuário informe dois números e realize operações matemáticas básicas.

---

## 🚀 Tecnologias Utilizadas

- Python 3
- Visual Studio Code (VS Code)
- GitHub

---

## ⚙️ Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão

---

## 📚 Aprendizados

Durante o desenvolvimento deste projeto foram praticados os seguintes conceitos:

- Variáveis
- Entrada de dados com `input()`
- Conversão utilizando `float()`
- Operações matemáticas
- Saída de informações com `print()`
